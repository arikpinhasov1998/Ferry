Ferry - copy and sync your files, safely
=========================================

What's in this folder
  ferry-gui  (ferry-gui.exe / ferry-gui.app)   the desktop app  <- start here
  ferry      (ferry.exe)                       commands, terminal app, background helper

No installation and no administrator rights needed.

First start
  Windows: double-click ferry-gui.exe. If "Windows protected your PC" appears:
           More info -> Run anyway.
  macOS:   right-click ferry-gui -> Open -> Open (only the first time).
  Linux:   ./ferry-gui   (if needed first: chmod +x ferry ferry-gui)

Your first copy
  Click "New copy", choose the Source and Destination folders, click "Run now".

Same with a command (macOS/Linux: ./ferry)
  ferry copy   SOURCE DEST            copy new and changed files
  ferry mirror SOURCE DEST            make DEST exactly like SOURCE
  ferry mirror SOURCE DEST --dry-run  only show what would happen
  ferry robo   SOURCE DEST /MIR /R:2  robocopy syntax
  ferry tui                           full-screen terminal app (servers)
  ferry service install               start Ferry automatically at login
  ferry telegram setup                control Ferry from Telegram
  ferry --help                        all commands

Safety: files that would be replaced or deleted are kept in
DEST/.ferry-archive/<date>/ - copy them back from there if you need them.

Portable mode: make an empty folder named "ferry-data" next to these files.
Ferry then keeps all settings, jobs and logs in it (great for USB sticks).

Clouds (Google Drive, OneDrive, S3...): put rclone (https://rclone.org/downloads/)
next to ferry, run "rclone config", then use remote:path as a folder.

Full guide: https://github.com/arikpinhasov1998/Ferry/blob/main/docs/GUIDE.md
